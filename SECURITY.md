# Security policy

## Reporting a vulnerability

Report it privately by email to `<contact address>`. Do not open a public
issue or pull request for a security problem.

Include what you found, how to reproduce it, and which commit or version you
tested. Do not include other people's data.

## What to expect

We aim to acknowledge a report within 7 days.

## Supported versions

Only `main`. There are no other supported versions.
